# 副業用 作品フォルダ

副業で作った作品（LP・Webページなど）を、1か所にまとめておくためのフォルダです。
**1つの作品 = 1つのフォルダ** というルールで整理します。

---

## フォルダの構成

```
LP用/
├── README.md        ← このファイル（使い方の説明書）
├── _template/       ← 新しい作品を作るときの「ひな形」
│   ├── index.html   ← ページの中身（文章・見出し・ボタンなど）
│   ├── css/
│   │   └── style.css ← ページの見た目（色・文字の大きさ・余白など）
│   ├── img/         ← 画像を入れる場所
│   └── memo.md      ← 作品についてのメモ（依頼主・金額・反省など）
└── works/           ← 完成した作品・制作中の作品をここに入れる
    ├── 2026-11_cafe-lp/
    ├── 2026-12_salon-lp/
    └── ...
```

### それぞれの役割

| 名前 | 何をするところ？ |
| --- | --- |
| `_template/` | 毎回ゼロから作らなくていいように用意した「ひな形」です。**ここは直接編集せず、コピーして使います。** |
| `works/` | 作品を入れる本棚のような場所です。作品ごとにフォルダを1つ作ります。 |
| `index.html` | Webページの「中身」を書くファイルです。ダブルクリックするとブラウザで表示できます。 |
| `css/style.css` | Webページの「見た目」を決めるファイルです。色やサイズを変えたいときはここを編集します。 |
| `img/` | 写真やロゴなど、ページで使う画像を入れます。 |
| `memo.md` | 作品の記録用メモです。ポートフォリオ作りや、次の見積もりの参考になります。 |

---

## 使い方：新しい作品を作るとき

### ① ひな形をコピーする
1. Finder で `_template` フォルダを選ぶ
2. `command + C`（コピー）→ `works` フォルダを開いて `command + V`（貼り付け）

### ② フォルダの名前を変える
コピーしたフォルダの名前を、次のルールで付けます。

```
年-月_作品の内容
```

例：
- `2026-11_cafe-lp`（2026年11月に作ったカフェのLP）
- `2026-12_salon-lp`（2026年12月に作ったサロンのLP）

> 💡 **名前は「半角英数字」と「-（ハイフン）」「_（アンダーバー）」だけにするのがおすすめです。**
> 日本語やスペースが入っていると、あとでWeb上に公開するときにうまく動かないことがあります。
> 先頭に年月を付けておくと、作った順番にきれいに並びます。

### ③ 作品を作る
- 文章を変えたい → `index.html` を編集
- 色や見た目を変えたい → `css` フォルダの中の `style.css` を編集
- 画像を使いたい → `img` フォルダに画像を入れる
  （`index.html` には `<img src="img/画像の名前.jpg" alt="画像の説明">` のように書きます）

### ④ 表示を確認する
`index.html` をダブルクリックすると、ブラウザで今の状態を確認できます。
ファイルを保存したら、ブラウザで `command + R`（再読み込み）すると最新の状態になります。

### ⑤ メモを書く
完成したら `memo.md` に依頼主・金額・こだわったポイントなどを書いておきましょう。

---

## ファイルの編集のしかた

`index.html` や `style.css` は、ふつうの「テキストエディタ」で開いて編集します。
無料の **Visual Studio Code（VS Code）** を使うと、色分けされて見やすいのでおすすめです。

ファイルの中にある `<!-- ○○ -->`（HTML）や `/* ○○ */`（CSS）は **コメント** といって、
ページには表示されない「メモ書き」です。どこに何が書いてあるかの目印にしてください。

---

## 困ったときは

- **ページが真っ白／崩れた** → 直前に編集したところを元に戻してみましょう。`command + Z` で1つ前に戻せます。
- **画像が表示されない** → 画像のファイル名と、`index.html` に書いた名前が完全に同じか（大文字・小文字、拡張子 `.jpg` / `.png` も含めて）確認しましょう。
- **ひな形を壊してしまった** → `_template` を直接編集しない、というルールを守っていれば作品側だけの問題なので安心です。
